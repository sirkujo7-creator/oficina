# Oficina · Concurso Docente 2026-27

App web instalable para preparar el Concurso Docente (CNSC) en Ciencias Sociales: casos tipo Saber, actividades repetibles y repaso espaciado. Funciona sin conexión.

- `js/datos-casos.js`: banco de casos de análisis.
- `js/datos-actividades.js`: bancos de las 7 actividades.
- `js/app.js`: lógica de la app.
- `sw.js`: funcionamiento sin conexión. Al publicar cambios, sube el número de `VERSION` para que la app avise que hay versión nueva.

Herramienta de estudio no oficial.
